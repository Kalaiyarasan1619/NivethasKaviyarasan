# 💒 திருமண அழைப்பிதழ் வலைத்தளம் (Marriage Invitation Website)

A royal South Indian / Tamil Hindu Marriage Invitation website built with **React**, **TypeScript**, and **Tailwind CSS**, styled faithfully after traditional royal wedding cards.

---

## ✨ Features

1. **Pixel-Perfect Home Screen Hero Design**:
   - Deep royal maroon/burgundy gradient background with golden borders and corner ornamental flourishes.
   - Top-left initials: `V ♥ D` (or customized).
   - Top-right music button: `🎵 இசையை இயக்கவும்` / `⏸ இசையை நிறுத்தவும்` with animated soundwave equalizer.
   - Auspicious golden Lord Vinayagar (Ganesha) emblem.
   - Traditional family blessing & Tamil invocations (`இறைவன் அருளுடனும், பெரியோர்களின் ஆசியுடனும்`).
   - Prominent Tamil typography for couple names (`வி. விஜய் ♥ க. திவ்யா`) with matching English subtitle.
   - Wedding date display (`13 NOVEMBER 2026`).
   - Interactive gold invitation button (`அழைப்பிதழ் திறக்கப்பட்டது ✓` / `OPEN OUR INVITATION`) with celebratory golden confetti burst!

2. **Full Auspicious Wedding Details (சுப நிகழ்ச்சிகள்)**:
   - **⏳ Live Countdown Timer**: Days, hours, minutes, and seconds to the auspicious Muhurtham.
   - **📅 Event Schedule**:
     - வரவேற்பு நிகழ்ச்சி (Reception): 12 Nov 2026, 6:30 PM onwards.
     - திருமண முகூர்த்தம் (Muhurtham): 13 Nov 2026, 6:00 AM - 7:30 AM (விருச்சிக லக்னம்).
     - அறுசுவை திருமண விருந்து (Grand Feast).
   - **📍 Venue & Navigation**:
     - Hall address with 1-click **Google Maps** directions.
     - Family contact phone numbers.
   - **💑 Couple & Parents Details**:
     - Father and mother names for both Bride and Groom.
   - **💌 Guestbook & Wishes (வாழ்த்துகள்)**:
     - Guests can type their names and send heartfelt wedding wishes.
     - Interactive celebration confetti.
     - Stored locally with `localStorage`.
   - **🗓 Add to Calendar & Share**:
     - Add directly to Google Calendar.
     - Download `.ics` calendar reminder.
     - Native Web Share / Copy Link.

3. **🎵 Auspicious Nadaswaram / Shehnai Music**:
   - Built-in soothing Carnatic Mangala Vathiyam / Shenai melody player using Web Audio API (works 100% offline, zero latency, no broken audio URLs).

4. **⚙️ Live Customizer Drawer**:
   - Floating button on bottom-right to switch between:
     - **Preset 1**: Exact image replica (`விஜய் & திவ்யா`)
     - **Preset 2**: `நிவேதா & கவியரசன்` (Nivetha & Kaviyarasan)
     - **Custom**: Edit any bride/groom name, date, venue, or phone number in real time!

## 🚀 How to Run

```bash
# Navigate to the project directory
cd "d:\NivethasKaviyarasan\Invitation"

# Start the development server
npm run dev

# Open in your browser:
# http://localhost:5173
```

To build for production:
```bash
npm run build
```
